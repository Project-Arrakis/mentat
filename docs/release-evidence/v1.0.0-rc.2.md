## Security Posture

- Runtime command behavior remains read-only.
- RBAC remains restricted by default.
- The optional addon remains zero-permission.
- The bot does not mount Docker, connect to the database, read game files,
  execute shell commands, or call write-capable adapter routes.
- No unresolved medium, high, or critical security finding is known.
