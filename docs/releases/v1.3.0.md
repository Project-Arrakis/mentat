# Release v1.3.0

Release date: 2026-07-03

## Summary

Read-only notifications (R1.3). Adds scheduled status posts, readiness alerts,
and incident digest summaries. All output remains read-only with channel
allow-lists and rate limits.

## Compatibility

Same v1.0.0 adapter boundary. No new adapter routes required.

## New in v1.3.0

- Scheduled status posts to allow-listed channels
- Readiness alert subscriptions
- Incident digest summaries
- Channel allow-list configuration
- Rate limiting and opt-in defaults

## Security Posture

- Channel allow-lists prevent unintended public exposure
- Rate limits prevent abuse
- Read-only output only
- Opt-in configuration (no default channels)

## Release Artifacts

- `discord-readonly-bot-v1.3.0.tar.gz`

- `dune-awakening-selfhost-discordbot.cdx.json.sha256`

## Known Limitations

- Alert subscriptions are bot-internal; no webhook or external notification.
- Write-capable commands remain out of scope.
