# Release v1.0.0

Release date: 2026-07-03

## Summary

Stable read-only production release of the Dune Awakening Self-Host Discord Bot.
Promotes the validated v1.0.0-rc.1 candidate to the first stable GA. No command
surface, RBAC, or behavior changes from the release candidate.

## Compatibility

- Bot repository: `yacketrj/Arrakis-Control-Panel`
- Upstream source of truth:
  `Red-Blink/dune-awakening-selfhost-docker@5163bd8`
- Upstream tag reviewed: `v1.3.41`
- Adapter boundary: read-only routes only

## Included Commands

- `/dune about`
- `/dune ping`
- `/dune health`
- `/dune status`
- `/dune status-summary`
- `/dune readiness`
- `/dune services`

## Security Posture

Same as v1.0.0-rc.1:

- RBAC restricted by default, fails closed without configured principals.
- No Docker socket, database, game-file, shell, or write-capable adapter access.
- Zero-permission addon package.
- Shared redaction for credentials, emails, SteamIDs, FuncomIDs, real names.
- STRIDE, privacy, SOC 2 alignment, supply-chain evidence current.
