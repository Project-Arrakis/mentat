# Release v1.0.0-rc.1

Release date: 2026-07-03

## Summary

Release candidate for the read-only `R1.0.0` production target. This
prerelease keeps the Discord bot read-only and packages the completed repository
evidence needed for operator validation before stable promotion.

## Security Posture

- Runtime command behavior remains read-only.
- RBAC remains restricted by default.
- The optional addon remains zero-permission.
- The bot still does not mount Docker, connect to the database, read game
  files, execute shell commands, or call write-capable adapter routes.
- Redaction still covers credentials, authorization headers, emails, SteamIDs,
  FuncomIDs, and explicit real-name fields before output reaches Discord or
  logs.
- The project is not expected to process PCI/payment-card data.
- No unresolved medium, high, or critical security finding is known from the
  current read-only production readiness review.

## Verification

Release candidates must pass:

- `npm run check`
- `npm audit --audit-level=moderate`
- Semgrep
- Gitleaks history and worktree scans
- Trivy filesystem scan
- Docker image build
- Trivy image scan
- published artifact checksum verification

Operator-owned validation before stable promotion:

- test-guild slash command registration
- live private WebUI adapter smoke
- runtime Discord command smoke
- Docker start and healthcheck
- owner go/no-go decision in the stable release-preparation PR

## Known Limitations

- This is a prerelease candidate, not the default stable operator release.
- No live Discord guild or live WebUI deployment test is bundled with the
  release; those remain operator smoke tests.
- No write-capable commands are included.
- Stable `v1.0.0` promotion requires a separate release-preparation PR after
  this candidate's artifacts and validation evidence are reviewed.
