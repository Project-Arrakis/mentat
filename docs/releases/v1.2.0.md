# Release v1.2.0

Release date: 2026-07-03

## Summary

Read-only detail expansion (R1.2). Adds enhanced detail output for services and
readiness commands. All commands remain read-only.

## Compatibility

- Bot repository: `yacketrj/dune-awakening-selfhost-discordbot`
- Upstream source of truth: `Red-Blink/dune-awakening-selfhost-docker`
- Adapter boundary: read-only routes only

## New in v1.2.0

- `/dune services detail` - per-service status with metadata
- `/dune readiness detail` - granular readiness component breakdown
- Maintenance window metadata display (when upstream exposes safe data)
- Full adapter contract evidence and fixture coverage for all new fields
- Route compatibility tests for detail endpoints
- Redaction tests for sensitive fields

## Security Posture

Enhanced but unchanged risk profile. New detail fields are redacted per existing
policy. No write-capable commands added.
