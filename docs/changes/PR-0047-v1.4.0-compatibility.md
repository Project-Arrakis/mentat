# PR-0047: v1.4.0 Compatibility Hardening

## Summary

R1.4 release train: compatibility hardening. Adds upstream drift detection,
fixture refresh workflow, and stronger route compatibility tests.

## User Impact

Operators get earlier warning of upstream adapter changes that could affect
bot behavior. All commands remain read-only.

## Security Impact

- Command surface: unchanged (no new commands)
- RBAC or authorization: unchanged
- Secret handling: unchanged
- Data crossing Discord/bot/WebUI boundaries: unchanged
- Network exposure: unchanged
