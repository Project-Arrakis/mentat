# PR-0046: v1.3.0 Read-Only Notifications

## Summary

R1.3 release train: read-only notifications. Adds scheduled status posts,
readiness alerts, and incident digest summaries.

## User Impact

Operators can subscribe Discord channels to scheduled status updates and
readiness state change alerts. All output is read-only.

## Security Impact

- Command surface: no new slash commands; new scheduled/alarm subsystem
- RBAC or authorization: channel allow-list enforced; no Discord role bypass
- Secret handling: unchanged shared redaction
- Data crossing Discord/bot/WebUI boundaries: same adapter contract, read-only
- Network exposure: unchanged

## Least Privilege

- Same Discord intents
- Channel allow-lists restrict output destinations
- Rate limits prevent API abuse
