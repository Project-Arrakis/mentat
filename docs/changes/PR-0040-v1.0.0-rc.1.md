# PR-0040: Prepare v1.0.0-rc.1

## Summary

Prepares the `v1.0.0-rc.1` release candidate for the read-only `R1.0.0`
production target. The candidate packages the completed read-only command set,
operator validation path, upstream `v1.3.41` compatibility evidence, current
security review, and release-roadmap evidence for prerelease validation.

## User Impact

Operators get a GitHub prerelease candidate with checksummed addon and SBOM
artifacts after the release tag is cut. Runtime bot behavior remains read-only.

## Security Impact

- Command surface: unchanged.
- RBAC: unchanged.
- Secrets handling: unchanged.
- Data crossing Discord, the bot, and the WebUI adapter: unchanged.
- Network exposure: unchanged.
- Release posture: candidate artifacts use the same gates, SBOM, and checksum
  requirements as stable releases.
- Security findings: no unresolved medium, high, or critical finding is known
  from the current read-only production readiness review.

## Least Privilege

Runtime least privilege is unchanged. The optional addon remains
zero-permission and packages under the prerelease version.

## Tests and Evidence

- `npm run check`
- `npm audit --audit-level=moderate`
- local addon and SBOM checksum verification
- `npm run smoke:adapter` against the local mock adapter on loopback
- PR #40 hosted gates passed: dependency audit, dependency review, secret scan,
  Semgrep SAST, test, Trivy filesystem scan, and Trivy image scan.

## Known Limitations

This PR prepares a prerelease candidate only. Stable promotion to `v1.0.0`
requires a separate PR, clean gates, published artifact checksum verification,
operator-owned smoke evidence or approved deferral, and owner go/no-go.
