# PR-0059: v2.3.0 Scheduled-Post Configuration Writes

## Summary

R2.3 release train: bot-owned scheduled post configuration commands. Operators can configure scheduled status post timing, channels, and content preferences.

## User Impact

Operators with write permissions can configure scheduled posts via Discord. Dry-run/preview available where supported. All changes confirmed and audited.

## Security Impact

- Command surface: expanded (scheduled post config)
- RBAC or authorization: write-specific RBAC; observer roles cannot execute
- Secret handling: unchanged
- Data crossing Discord/bot/WebUI boundaries: configuration payloads to adapter
- Network exposure: unchanged

## Least Privilege

Write-specific RBAC, confirmation required, ephemeral responses by default.
