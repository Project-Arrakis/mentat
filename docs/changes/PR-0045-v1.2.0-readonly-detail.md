# PR-0045: v1.2.0 Read-Only Detail Expansion

## Summary

R1.2 release train: read-only detail expansion. Adds `/dune services detail`
and `/dune readiness detail` subcommands for enhanced read-only output.

## User Impact

Operators get richer detail from services and readiness commands. All new
output is read-only and redacted per existing policy.

## Security Impact

- Command surface: added `/dune services detail`, `/dune readiness detail`
- RBAC or authorization: new commands require same tier as parent commands
- Secret handling: shared redaction covers new fields
- Data crossing Discord/bot/WebUI boundaries: same adapter contract
- Network exposure: unchanged

## Least Privilege

- Same Discord intents and bot permissions as v1.0.0
- New detail commands use same adapter routes (configurable detail query params)
