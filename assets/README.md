# Bot Imagery

Discord bot avatar icon in multiple formats.

- `bot-icon-1024.png` — Full resolution (use for Discord Developer Portal)
- `bot-icon-256.png` — Medium resolution
- `bot-icon-128.png` — Small resolution
- `bot-icon-64.png` — Thumbnail
- `bot-icon.ico` — Windows icon format
- `bot-icon.svg` — Scalable vector source

## Using as Discord Bot Avatar

1. Go to [Discord Developer Portal](https://discord.com/developers/applications)
2. Select your application
3. Go to **Bot** tab
4. Under **Display Name**, click the avatar circle
5. Upload `bot-icon-1024.png`

Regenerate with: `python3 scripts/generate-icons.py`
